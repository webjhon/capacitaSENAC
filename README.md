<h1>📁 Estrutura Base de Projeto – Capacitação SENAC</h1>

<p>
Este projeto foi desenvolvido como parte da capacitação orientada pelo 
<strong>Professor João Carlos</strong> e pela <strong>Professora Luciana de Oliveira</strong> 
no <strong>SENAC</strong>.  
O objetivo é fornecer um <strong>template mínimo viável</strong> para que alunos iniciem seus projetos
com uma organização clara, profissional e escalável. 🚀
</p>

<hr>

<h2>📦 Estrutura de Pastas</h2>

<div class="folder">
    <h3>📁 <code>config/</code></h3>
    <p>Contém arquivos de configuração geral do projeto, setups, constantes e demais ajustes essenciais.</p>
</div>

<div class="folder">
    <h3>📁 <code>database/</code></h3>
    <p>Pasta destinada a arquivos de banco de dados, como migrations, seeds ou scripts SQL.</p>
</div>

<div class="folder">
    <h3>📁 <code>docs/</code></h3>
    <p>Documentação do projeto: requisitos, diagramas, anotações e materiais de apoio. 📝</p>
</div>

<div class="folder">
    <h3>📁 <code>public/</code></h3>
    <p>Arquivos públicos acessíveis pelo usuário final, como imagens, CSS, JavaScript e assets estáticos.</p>
</div>

<div class="folder">
    <h3>📁 <code>src/</code></h3>
    <p>O coração do projeto! Contém o código-fonte principal: módulos, classes, funções, controllers, etc. 💻</p>
</div>

<div class="folder">
    <h3>📁 <code>tests/</code></h3>
    <p>Scripts de testes automatizados para garantir que tudo funcione conforme o esperado. ✔️</p>
</div>

<div class="folder">
    <h3>📄 <code>.gitignore</code></h3>
    <p>Define arquivos e pastas que não devem ser enviados ao repositório Git.</p>

    <h3>📄 <code>LICENSE</code></h3>
    <p>Licença do projeto, permitindo uso, modificação e distribuição conforme definido.</p>

    <h3>📄 <code>README.md</code></h3>
    <p>Documento principal com explicações sobre o projeto, instruções e informações gerais.</p>
</div>

<hr>

<h2>🎯 Objetivo do Template</h2>
<p>
Este template oferece uma base clara e profissional para que qualquer aluno possa iniciar projetos com organização e boas práticas desde o começo.  
A intenção é facilitar o aprendizado e estimular a estruturação correta de aplicações reais. 💡
</p>
